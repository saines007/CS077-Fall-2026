### Clone a repository from Github to local files to create a pathway and proper organization
### Create a new project and open the appropriate C# console with (.NET Framework) in Visual Studio 
### Complete the project within the parameters of the assignment and ensuring the container is closed ex. string name = "";

### If/else statement either shows the country of origin or a sorry message
### Commit changes to Github via Visual Studio and ensuring proper organization
### Share within community to learn/teach from others (Discord)
### Submit Assignment
### Build the next version with the necessary features to improve the user experience
